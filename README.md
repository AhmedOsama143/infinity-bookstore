# Infinity Bookstore | مكتبة إنفينيتي

Online bookstore for Egyptian secondary-school students. Multi-branch (Kafr El-Dawwar + Alexandria) with per-branch inventory, pickup/delivery, a 10-book cap per student, free shipping on orders ≥ 2,500 EGP, and a separate admin dashboard.

**Stack:** Next.js 15 + TypeScript + Tailwind · Supabase (Postgres + Auth + Storage + Realtime) · Vercel · Sentry · Plausible

See [`PROJECT_PLAN.md`](./PROJECT_PLAN.md) for the full specification and phased implementation plan.
